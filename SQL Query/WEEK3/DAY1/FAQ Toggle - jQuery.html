Frequently Asked Questions

1. What is jQuery?
jQuery is a JavaScript library used for DOM manipulation.
2. Why use jQuery?
It simplifies JavaScript coding and event handling.
3. What is slideToggle()?
It shows or hides elements with a sliding animation.
4. Is jQuery still used?
Yes, many legacy and enterprise projects still use jQuery.
5. What is DOM manipulation?
Changing HTML content dynamically using scripts.
